ЧТО ЭТО
-------------------------------------------------------------------------------
Lumé Beauty — готовое SaaS-решение для салонов красоты, работающее как
Mini App внутри Telegram. Клиент находит салон в Telegram → нажимает одну
кнопку → внутри Telegram открывается полнофункциональное приложение для
записи, без скачивания, без логинов, без СМС-кодов.

Салон получает: онлайн-запись, CRM, программу лояльности, аналитику,
маркетинг — всё в одном месте, всё через тот мессенджер, которым клиенты
уже пользуются.


КЛЮЧЕВЫЕ ПРЕИМУЩЕСТВА ДЛЯ САЛОНА
-------------------------------------------------------------------------------
• 0 ₽ за установку для клиента: не нужно скачивать app — открыл бота,
  нажал кнопку.
• Авто-авторизация: имя, фамилия, аватарка, язык — берутся из Telegram.
  Никаких SMS.
• Двуязычность: русский + узбекский. Каждую услугу можно перевести
  отдельно.
• Без подписки на дорогие сервисы: хостинг на Cloudflare стоит $0 для
  салона до 100 000 запросов в день.
• Полная админка: управление из браузера или прямо из Telegram.
• Уведомления через Telegram-бота — доходимость ~95%
  (vs SMS 60%, email 20%).

ДЛЯ КЛИЕНТА (MINI APP)
-------------------------------------------------------------------------------

>>> Запись онлайн
• 5-шаговый визард: филиал → услуги (можно выбрать несколько) →
  мастер → дата и время → подтверждение.
• Любой свободный мастер или выбор конкретного.
• Избранные мастера — сохраняются и показываются первыми.
• Блокировка слота на 5 минут — пока клиент думает, никто не перехватит.
• Защита от двойного бронирования — между всеми устройствами
  одновременно.
• Photo gallery услуг + рейтинг мастеров с отзывами.
• Поиск услуг + категории (Маникюр, Педикюр, Ресницы, Брови, Уход, Волосы).

>>> Программа лояльности
• 4 уровня кешбэка: Bronze 5% → Silver 8% → Gold 12% → Platinum 15%.
• Автопересчёт уровня после каждого визита.
• Бонусы начисляются при завершении визита.
• Использование бонусов при следующей записи (до 50% от стоимости).
• День рождения — клиент указывает дату, в день рождения автоматически
  приходит сообщение со скидкой 25%.
• Реферальная программа — пригласи подругу по личной ссылке, обе получают
  +50 000 бонусов после её первого визита.
• Промокоды с автоприменением.

>>> Ваучеры и абонементы
• Подарочные ваучеры — салон выпускает код типа LUME-AB12CD на любую
  сумму. Клиент дарит → получатель применяет при записи.
• Абонементы — например «10 маникюров со скидкой 15%». Каждая запись
  списывает один визит.

>>> Профиль клиента
• Все предстоящие записи с кнопками «Перенести» и «Отменить».
• «Поделиться записью» — расшарить подруге в Telegram.
• «Повторить запись» — записаться к тому же мастеру на ту же услугу
  одним тапом.
• История визитов с возможностью оставить отзыв (1–5 звёзд + текст).
• Мой календарь — месячная сетка с метками визитов.
• Карта филиалов (Yandex Maps) с маршрутом до выбранного.
• Push-уведомления — кроме Telegram, можно подписаться на нативные
  push телефона.

>>> Автоматические уведомления клиенту
• При создании записи — подтверждение.
• За 24 часа до визита — напоминание.
• За 2 часа до визита — повторное напоминание.
• При отмене/подтверждении админом — уведомление со статусом.
• В день рождения — поздравление со скидкой.
• При начислении бонусов — «Вам начислено X бонусов».


ДЛЯ АДМИНИСТРАТОРА САЛОНА
-------------------------------------------------------------------------------

>>> Управление записями
• Все записи с фильтрами: ожидают / подтверждены / завершены / отменены /
  не пришёл.
• Создать запись вручную — для walk-in клиентов и звонков.
• 4 действия одним тапом: Подтвердить / Завершить (начисляет бонусы) /
  Не пришёл / Отменить (с указанием причины).
• Массовые действия — выбрать несколько и подтвердить/отменить разом.
• Поиск по мастеру / услуге / филиалу.
• Группировка по статусу.

>>> CRM — база клиентов
• Все клиенты с поиском по имени, username, телефону, ID.
• Карточка клиента: бонусы, визиты, потрачено всего, день рождения,
  контакты, история записей.
• Приватные заметки для админа (аллергии, предпочтения).
• Экспорт в CSV для Excel.
• Автоматический трекинг: каждый клиент появляется при первой записи.

>>> Аналитика и дашборд
• Расписание на сегодня — все записи по времени с именами клиентов.
• Графики выручки (за 7 дней / 30 дней / 12 месяцев) — line + bar charts.
• Загрузка мастеров — кто сколько обслужил.
• Сводка по статусам — сегодня / ожидают / подтверждено / завершено /
  отменено.
• Доходы и комиссии мастеров — выручка + автоматический расчёт комиссии
  (настраиваемый %).
• Календарь дня по мастерам — визуальная сетка время × мастера, каждая
  запись в своей ячейке.

>>> Управление каталогом
• Услуги — добавить/редактировать/удалить, обложка, цена, длительность,
  описание, категория, признак «популярная».
• Филиалы — адрес, телефон, часы работы, фото.
• Мастера — фото, рейтинг (авто-обновляется по отзывам), стаж,
  услуги/филиалы, рабочее время по дням недели, % комиссии.
• Акции — заголовок, бейдж, описание, реальная скидка %, выбор услуг
  к которым применяется.
• Ваучеры — выпустить (с авто-генерацией кода), указать сумму,
  владельца, срок.
• Абонементы — выдать клиенту пакет на N визитов конкретной услуги.

>>> Маркетинг и коммуникация
• Массовая рассылка через бота всем клиентам — текст с HTML-форматированием.
• Отзывы клиентов — модерация (опубликовать/скрыть), ответ от салона
  (виден на странице услуги).
• Промокоды с настройкой реальной скидки и привязкой к конкретным услугам.

>>> Двуязычность интерфейса
• Каждой услуге/филиалу/мастеру/акции админ может задать перевод
  на узбекский.
• Клиент с UZ-языком видит узбекский; без перевода — фолбэк на русский.
• Готовая инфраструктура для других языков (английский и т.д.).


TELEGRAM-БОТ

• Кнопка «✨ Lumé» в меню бота — открывает Mini App.

MULTI-ADMIN

================================================================================
  ТЕХНИЧЕСКАЯ БАЗА
================================================================================

Frontend:     React 19 + TanStack Start (современный SSR, быстрая загрузка)
UI:           Tailwind 4 + shadcn/ui (премиум-дизайн)
База данных:  Cloudflare D1 (SQL, $0 до 5 ГБ)
Файлы:        Cloudflare R2 ($0 до 10 ГБ, аналог Amazon S3)
Хостинг:      Cloudflare Workers ($0 до 100 000 запросов/день, глобальный CDN)
Авторизация:  Telegram WebApp initData + HMAC (без СМС, без паролей)
Уведомления:  Telegram Bot API + Web Push (VAPID) — 2 канала
Расписание:   Cloudflare Cron Triggers (напоминания каждые 15 мин)
Карты:        Yandex Maps Embed (бесплатно, без API-ключа)
Графики:      Recharts (профессиональные графики выручки)

Деплой: одна команда `npx wrangler deploy` → доступно по всему миру
через ~30 секунд.

================================================================================
  АРГУМЕНТЫ ДЛЯ ПРОДАЖИ
================================================================================

БОЛЬ САЛОНА
-------------------------------------------------------------------------------
• Запись через WhatsApp / Direct = беспорядок, забывают.
• Клиенты не приходят — нет автонапоминаний.
• Нет программы лояльности → клиенты уходят к конкурентам.
• Нет единого учёта → не знают сколько визитов у Анны, сколько потратила.
• Не могут проверить кто сегодня записан без админа на месте.


РЕШЕНИЕ
-------------------------------------------------------------------------------
• Все записи в одной системе, доступны из Telegram админа в любой момент.
• Автонапоминания — посещаемость растёт на 15-25%.
• Программа лояльности увеличивает повторные визиты на 30-40%.
• CRM показывает топ-клиентов и тех кто давно не приходил —
  можно сделать рассылку.
• Удалённый контроль: владелец видит дашборд из дома.


ЦИФРЫ ДЛЯ ПРЕЗЕНТАЦИИ
-------------------------------------------------------------------------------
• Средний чек 180 000 сум.
• Посещаемость без напоминаний 75%, с напоминаниями 90%.
• Салон на 30 записей в день теряет ~7 записей × 180 000 =
  ~1.3 млн сум в день на «забывчивости».
• За месяц это ~39 млн сум потерянной выручки.
• Lumé окупается за 2-3 дня работы.
